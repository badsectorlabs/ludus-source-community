## Build your own

Start from the annotated [role starter in ludus-source-template](https://github.com/badsectorlabs/ludus-source-template/tree/main/ansible/roles), then open a PR to vendor it here — see [Contributing](../../README.md#contributing).

## Inspiration

Browse the official Bad Sector Labs roles in [ludus-source-bsl](https://github.com/badsectorlabs/ludus-source-bsl/tree/main/ansible/roles).

## Not vendored

A vendored directory must be a single role at its repo root, so these multi-role repos can't be included — install them per their own READMEs:

- [ChoiSG/ludus_ansible_roles](https://github.com/ChoiSG/ludus_ansible_roles) — `ludus_child_domain`, `ludus_child_domain_join`, `ludus_create_ad_trust`, `ludus_disable_defender_gpo`, `ludus_run_ps_scripts`
- [curi0usJack/Ludus-MDE-MDI-Roles](https://github.com/curi0usJack/Ludus-MDE-MDI-Roles) — `ludus_enable_asr`, `ludus_enable_mdi_gpo`
- [frack113/my-ludus-roles](https://github.com/frack113/my-ludus-roles) — `ludus_graylog_server`
- [ZephrFish/ludus-defender-lab](https://github.com/ZephrFish/ludus-defender-lab) — MDE/MDI Defender lab kit (roles + playbook)
